01 · DIAGNOSIS PURPOSE

진단 목적 — BEMS를 “보는 시스템”에서 “최적 운전을 만드는 시스템”으로 확장

설계값과 실제 수요·운전상태 사이의 Gap을 지속적으로 관리

대형 건물은 설계 안전율, 설치·시운전 상태, 제어기능, 설비정비와 실제 수요변화로 인해 설계 당시 의도와 다른 상태로 운전될 수 있습니다. 본 제안은 기존 BEMS 데이터를 활용하여 실제 설비의 수요·성능·제어·가동대수를 진단하고, 최적운전 조건을 관리자에게 실시간으로 제공해 일회성 개선이 아닌 지속적인 성능개선을 구현하는 것을 목표로 합니다.

02 · TARGET SYSTEM

초고층 복합건물의 대규모 열원·공조설비를 통합 분석

설비군 주요 분석대상 진단 관점
열원냉동기 · 냉각탑 · 보일러 · 열교환기효율·부하율·운전조합·설정조건
수배관냉수·냉각수·온수·급탕 등 펌프유량·가동대수·제어상태·부분부하
공조공조기 · FCU · 급기팬 · 배기팬 · 에어컨수요·스케줄·제어·운전효율
BEMS전력 · 연료 · 용수 · 일기 · 온도 · 유량데이터 정합성·추세·상관관계·성능지표

실제 건물명, 층수, 연면적, 구역명과 상세 설비수량은 고객 비식별을 위해 공개하지 않았습니다.

03 · DIAGNOSIS METHOD

진단 방법 — 설계검토 + 계측 정합성 + BEMS 데이터분석 + 실시간 성능진단

분석영역 수행방법 목적
설계·부하 검토 건물·구조체 설계조건, Zone별 면적과 냉난방부하, 열원설비 설계성능 비교 설계용량과 실제 수요의 차이 파악
계측 정합성 이상데이터 분석, 검교정 장비 실측비교, 계산식 보정, 필요 시 계측기 교정·교체 성능계산의 신뢰도 확보
BEMS 데이터분석 대표 계절 1주일의 5~15분 데이터로 소비량·효율·부하율과 인자간 상관관계 분석 최적화 시나리오 작성
BPOS 실시간 진단 에너지·수요·성능·제어·가동대수 진단 및 실시간 운전가이드 현재 운전상태와 최적 시나리오 비교
계절별 최적화 수요·외기·설비환경 변화에 따라 가동대수·설정값·운전시나리오 지속 개선 Continuous Commissioning 구현

04 · DIAGNOSIS PROCESS

진단 및 컨설팅 절차

단계 수행내용
1. 부하계산 검토설계조건·Zone별 냉난방부하·열원설비 설계성능 검토
2. 설비사양 DB냉동기·냉각탑·보일러·펌프·공조기·팬 등 주요 설비사양 DB 구축
3. 데이터 정합성전력계·온도센서·유량계 이상데이터 확인과 교정·보정
4. BEMS 데이터분석전력·입출구온도·유량 데이터를 이용한 소비량·효율·부하율·상관관계 분석
5. BPOS 구축모니터링맵, 최적화 시나리오, 프로그램 설치·시운전 및 운전가이드 구성
6. 운전최적화실시간 진단과 계절별 가동대수·제어·운전조건 최적화
7. 교육·사후관리운영자 활용교육, 개선과정 공유, 사업 종료 후 계절별 사후관리

05 · DATA QUALITY

기존 BEMS 활용의 핵심은 “데이터가 맞는가”부터 확인하는 것

추가 계측을 최소화하되, 정합성 문제가 있으면 교정·보정

제안은 기존 BEMS 저장데이터를 최대한 활용하는 방식입니다. 다만 전력계·온도센서·유량계의 이상값이 확인되면 검교정된 장비와의 실측 비교, 계산식 보정, 필요 시 계측기 교정 또는 교체를 수행한 후 분석에 사용하도록 구성되어 있습니다.

07 · BPOS

BPOS — Building Performance Optimization System

기능 주요 내용
에너지진단건물·장소·설비별 현재 에너지사용 상태 평가
수요진단Schedule과 실제 운전상태를 비교하여 불필요 운전 확인
성능진단개별기기의 효율상태와 에너지성능 평가

가동대수진단현재 가동대수와 부하에 적합한 최적 가동대수 비교
조회·분석Trend·상관관계·평가·통계 분석
실시간 운전가이드실제 운전데이터와 최적운전 시나리오를 비교해 관리자에게 가이드 제공

08 · CONTINUOUS COMMISSIONING

실시간 운전가이드 + 시나리오 개선의 이중 구조

구분 운영방식
실시간 최적화 에너지·수요·성능·제어·가동대수를 실시간 진단하여 현재 운전에 대한 가이드를 제공
시나리오 최적화 데이터분석 → 문제점 확인 → 개선방안 → 실행 → 결과확인을 반복해 최적운전 시나리오 자체를 갱신
핵심은 “한 번 맞춘 설정값”이 아니라 변화에 따라 계속 다시 최적화하는 것

계절, 이용률, 외기조건, 설비상태가 변하면 최적 운전조건도 달라집니다. 따라서 BPOS는 현재 운전을 실시간 진단하는 기능과, 분석결과를 바탕으로 최적 시나리오를 지속 개선하는 기능을 함께 사용하도록 제안되었습니다.

10 · EXPECTED EFFECT

제안단계 기대효과

연간 3~10% 에너지 절감 목표 + 지속적 최적화에 따른 추가 절감

제안서에서는 BPOS 기반의 운전최적화를 통해 연간 3~10% 에너지절감과, 이후 지속적인 최적화 활동에 따른 추가 절감을 기대효과로 제시합니다. 이는 실행 전 사업목표이며 특정 연간 절감량이나 비용절감 실적이 제시된 자료는 아닙니다.

부대효과내용
지속 에너지관리일회성 진단이 아닌 실시간/계절별 성능개선 체계
M&V 활용ESCO 및 에너지절감사업의 성과확인 도구로 활용 가능
설비 수명저효율·비정상 운전의 조기발견을 통한 설비관리 지원
운영부담실시간 진단과 운전가이드를 통한 관리업무 지원

11 · M&V

3~10% 목표는 실행 후 Baseline 기반으로 검증

건물의 사용조건 변화와 절감효과를 분리해서 평가

초고층 복합건물의 에너지사용은 외기온도, 재실·이용률, 영업시간, 냉난방부하와 운영조건에 따라 크게 달라집니다. 따라서 개선 전후 사용량만 비교하지 않고 주요 영향인자를 반영한 Baseline을 구축한 뒤, 개선기간 실제 사용량과 비교하여 절감성과를 검증하는 것이 적절합니다.
