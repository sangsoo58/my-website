데이터센터 냉각탑 설정온도 최적화를 통한
냉동기·냉각탑 통합 냉방전력 저감

다중 IDC의 냉방설비 분석에서 도출된 냉각탑 설정온도 개선대안을 독립적으로 검토하여, 외기 습구온도와 냉동부하에 따라 냉각수 공급온도를 조정하고 냉동기 전력과 냉각탑 Fan 전력의 합이 최소가 되는 운전점을 찾는 사례.

1. 냉각수는 낮을수록 항상 좋은가?

냉동기 입장에서는 낮은 Condenser-water Temperature가 Condensing Pressure와 Compressor Lift를 줄여 효율을 높일 수 있다. 그러나 냉각수를 더 낮추기 위해 냉각탑 Fan을 더 빠르게 운전하면 Tower Power가 증가한다.

목표는 가장 낮은 냉각수온도가 아니라, 냉동기와 냉각탑을 합친 System kW가 최소가 되는 냉각수 운전점이다.

2. PUE·냉방설비 분석에서 냉각탑 설정온도 개선기회를 찾았다

다중 IDC의 센터별 PUE와 냉방설비 성능을 비교한 결과, 개선대안으로 고효율 EC Fan 교체·외기냉방·냉각탑 설정온도 최적화를 검토할 수 있었다.

CASE73은 이 가운데 Cooling Tower Set Point를 외기조건과 냉동부하에 맞춰 조정하는 운전최적화 문제에 초점을 둔다.

3. 냉각탑 성능의 기준은 외기 건구온도보다 습구온도다

증발냉각을 이용하는 Cooling Tower가 물을 얼마나 낮은 온도까지 냉각할 수 있는지는 Outdoor Wet-bulb Temperature의 영향을 크게 받는다. 따라서 동일한 냉각수 공급온도라도 습구온도가 낮은 날과 높은 날의 Tower 부담은 다르다.

4. Approach는 냉각탑이 습구온도에 얼마나 가까이 접근했는지를 보여준다

Cooling Tower Approach
Approach = Leaving Condenser-water Temperature − Outdoor Wet-bulb Temperature

Approach를 지나치게 작게 만들려면 Fan·Tower Capacity가 더 필요할 수 있으므로, 고정된 낮은 냉각수 Set Point를 연중 유지하기보다 기후조건과 System Energy를 함께 보는 것이 좋다.

5. Range와 Approach는 서로 다른 물리량이다

Range는 냉각탑으로 들어오는 Hot Water Temperature와 나가는 Cold Water Temperature의 차이다. ASHRAE는 정상상태에서 이 Range가 Heat Load와 Water Flow의 영향을 받으며, 냉각탑 크기 자체가 Range를 직접 결정하는 것은 아니라고 설명한다.

반면 Approach는 Leaving Condenser-water Temperature와 Entering-air Wet-bulb Temperature의 차이로, 주어진 Heat Load·Water Flow·Air Condition에서 Tower의 열적 성능을 보여주는 대표지표다.

Range = Tower Entering Water T − Tower Leaving Water T
Approach = Tower Leaving Water T − Entering Wet-bulb T

6. 작은 Approach는 좋은 Tower 성능을 의미하지만 ‘0°C’를 목표로 하지 않는다

Approach가 작다는 것은 냉각수가 외기 Wet-bulb에 더 가까워졌다는 뜻이다. 그러나 Wet-bulb는 증발냉각의 실질적인 하한에 가까우며, Approach를 계속 줄이려면 더 큰 Tower, 더 많은 Airflow 또는 더 높은 Fan Power가 필요하다.

따라서 경제적 최적점은 가장 작은 Approach가 아니라 Chiller·Tower·Pump의 전체 전력과 설비비를 함께 고려해 결정한다.

7. Merkel Theory — Cooling Tower는 열전달과 물질전달이 동시에 일어나는 장치다

Cooling Tower에서는 물과 공기가 직접 접촉하면서 Sensible Heat Transfer와 물의 Evaporation에 의한 Latent Heat Transfer가 동시에 일어난다. Merkel의 고전적 해석은 이 두 현상을 포화공기와 Bulk Air 사이의 Enthalpy Potential을 구동력으로 묶어 Tower Performance를 계산한다.

Merkel Concept
Water ↔ Air의 Sensible + Latent Heat Transfer → Enthalpy Difference를 Driving Force로 통합 → Tower Characteristic(KaV/L) 평가

이 이론 때문에 Cooling Tower 성능을 Dry-bulb만으로 설명하지 않고 Wet-bulb와 공기·물의 Heat/Mass Transfer로 해석한다.

8. Merkel 모델은 강력하지만 몇 가지 단순화 가정을 가진다

전통적인 Merkel 해석은 계산을 단순화하기 위해 Water-to-interface의 Mass-transfer Resistance, Bulk Water와 Interface 사이 일부 Temperature Difference, Evaporation에 따른 Water Flow 변화 등을 단순화한다. 따라서 실제 Tower의 정밀 성능평가에서는 Manufacturer Rating Data나 CTI/ASHRAE Performance Method와 함께 사용하는 것이 좋다.

9. Wet-bulb Reset은 기후조건을 냉각수 Set Point에 직접 반영한다

ASHRAE는 고정 Condenser-water Set Point보다 Outdoor Wet-bulb와 일정 Approach를 유지하도록 Set Point를 Reset하는 전략이 더 나은 기본전략이 될 수 있다고 설명한다. 외기가 서늘해지면 냉각수온도를 낮춰 Chiller Lift를 줄이고, Wet-bulb가 높아지면 달성하기 어려운 Set Point를 무리하게 요구하지 않는다.

10. Wet-bulb Reset의 장단점은 기후에 따라 달라진다

기후장점주의점
서늘·건조낮은 Wet-bulb로 냉각수온도 저감 잠재량 큼지나친 Tower Fan 운전·Chiller Minimum Lift 확인

서늘·습윤중간기·겨울의 낮은 Wet-bulb 활용 가능Approach·결빙·저온 운전제약

한국처럼 사계절이 뚜렷한 지역에서는 계절별 Wet-bulb 분포와 Cooling Load를 함께 분석하여 Reset Curve를 만드는 편이 합리적이다.

11. Tower Fan에도 Affinity Law가 적용되지만 실제 System Curve를 확인한다

Fan Affinity Concept
Airflow Q ∝ Speed N   |   Pressure ∝ N²   |   Fan Power ∝ N³

VFD Fan의 속도를 낮추면 Part-load Fan Power가 크게 감소할 수 있다. 그러나 실제 Tower는 Air Resistance, Fan/Motor Efficiency와 Cell 간 Airflow Interaction이 있으므로 세제곱 관계를 그대로 절감률로 사용하지 않고 현장 kW로 검증한다.

12. Cell Staging과 Fan Speed에는 또 하나의 최적화 문제가 있다

같은 Heat Rejection을 한 개 Cell의 높은 Fan Speed로 처리할지, 여러 Cell을 낮은 Speed로 운전할지는 Tower 구성과 부하에 따라 결과가 달라진다. ASHRAE의 Supervisory Control은 여러 Tower Cell이 있을 때 Fan Sequence와 개별 Fan Speed를 System Efficiency 관점에서 결정해야 함을 다룬다.

따라서 CASE73에서는 Cell 수 × Fan Speed × Approach × Chiller Lift를 하나의 운전조합으로 평가한다.

13. 여러 Cell을 저속으로 운전하는 전략도 반드시 실측 검증한다

Affinity Law만 보면 여러 Fan을 낮은 Speed로 운전하는 방식이 유리해 보일 수 있지만, Tower Cell의 Water Distribution, Minimum Flow, Plume/Recirculation과 Fan 효율 때문에 실제 결과가 달라질 수 있다. 따라서 Cell Staging Rule은 Tower Manufacturer의 운전제약과 실제 System kW를 함께 사용해 정한다.

14. ASHRAE Best Practice — Chiller 절감과 Tower Fan 증가를 동시에 본다

ASHRAE Handbook은 Tower Fan을 더 빠르게 돌려 Condenser-water Temperature를 낮추면 Chiller Lift와 Compressor Energy가 감소하지만, 지나치게 낮추면 Tower Fan 증가분이 Chiller 절감분을 넘어설 수 있다고 설명한다. 그래서 Condenser-water Set Point Reset에는 Outdoor Wet-bulb, Heat Rejection/Load와 Chiller Manufacturer의 Minimum Lift 조건을 함께 반영한다.

15. ASHRAE Guideline 36은 부하에 따라 목표 Lift를 Reset하는 방향까지 제시한다

동적 부하가 큰 Plant를 위한 ASHRAE Guideline 36의 Sequence는 Plant Part-load Ratio를 이용해 목표 Chiller Lift를 Reset하고, 저부하에서는 Tower Maximum Speed를 제한하여 달성 불가능한 Set Point를 쫓느라 Tower Energy를 낭비하지 않도록 한다.

즉 단순한 ‘Wet-bulb + 고정 Approach’보다 한 단계 발전한 Load-responsive Condenser-water Control이다.

16. DOE Best Practice도 Condenser-water Set Point를 Load와 Wet-bulb에 맞춰 Reset하도록 권고한다

미국 DOE Better Plants의 Process Cooling Best Practice는 Cooling Tower Fan과 Condenser-water Pump에 VFD를 적용하고, Condensing-water Entering Temperature Set Point를 Process Load와 Ambient Wet-bulb에 따라 Reset하는 것을 주요 Energy Performance Measure로 제시한다.

17. 해외 연구사례 — Legacy Chiller Plant에서도 Set Point Optimization이 가능하다

Washington D.C.의 기존 Chiller Plant를 대상으로 한 연구에서는 Cooling Load와 Wet-bulb Forecast를 이용한 Model Predictive 방식으로 Condenser-water Set Point를 탐색했다. 연구결과는 Chiller + Cooling Tower의 연간 에너지사용량에 대해 최대 약 9.67%의 절감 가능성을 Simulation 기반으로 제시했다.

이 값은 CASE73의 실적이 아니며, 기존 제어구조를 크게 바꾸지 않고도 Supervisory Set Point Optimization을 적용할 수 있음을 보여주는 해외 연구 Reference다.

18. 최근 현장사례 — AI가 Chiller와 Cooling Tower를 하나의 Plant로 최적화한다

2026년 발표된 Singapore의 3개 상업용 Chiller Plant 현장연구에서는 Chiller를 Neural Network로, Cooling Tower를 Weather-responsive Model로 구성하고 실시간 Cooling Demand와 Weather Condition에서 최적 Condenser-water Temperature와 Chiller Loading을 동시에 탐색했다.

논문은 현장 검증에서 최대 약 28%의 Energy Performance Improvement를 보고하지만, 여러 Plant-level 최적화가 결합된 결과이므로 이를 CASE73의 냉각탑 Set Point 단독효과로 사용하지 않는다.

19. 국내 현장연구도 DNN 기반 냉각수온도 최적화로 발전하고 있다

2026년 국내 실증연구에서는 DNN 기반 알고리즘이 실제 중앙냉방시스템의 운전조건별 예상전력을 이용해 최적 Condenser-water Temperature Set Point를 결정하고, 기존 고정 Set Point 운전과 System Efficiency를 비교했다.

이는 CASE73의 확대방향인 고정 Set Point → Wet-bulb Reset → Model-based Optimization → AI Adaptive Set Point의 기술발전 흐름과 잘 맞는다.

20. AI Control에서는 Wet-bulb를 무시하면 안 된다

ANN 기반 냉각수온도 최적화의 후속연구에서는 Training Data가 부족하거나 Outdoor Wet-bulb를 충분히 반영하지 않으면 실제 Cooling Tower가 AI가 요구한 Set Point를 만들지 못하는 이상구간이 나타날 수 있음을 보고했다.

따라서 AI가 제안한 Set Point에도 Wet-bulb + Minimum Feasible Approach, Chiller Lift, Tower Capacity와 같은 물리적 Safety/Feasibility Constraint를 반드시 둔다.

22. Baseline은 Wet-bulb·Cooling Load·Set Point를 함께 만든다

시간별 Outdoor Wet-bulb, 냉각수 공급·환수온도, Cooling Tower Fan kW/Speed, Chiller Load와 Chiller kW를 같은 시간축으로 정렬한다. 이를 통해 현재 Set Point가 어떤 외기·부하조건에서 사용되고 있는지 확인한다.

23. 고정 Set Point보다 Wet-bulb Reset을 검토한다

외기 습구온도가 낮아지면 같은 Approach를 유지하면서 Condenser-water Set Point를 낮출 수 있다. 반대로 습구온도가 높은 날에는 달성하기 어려운 낮은 Set Point를 고집해 Fan을 과도하게 운전하지 않도록 한다.

Concept
Condenser-water Supply Set Point ≈ Outdoor Wet-bulb + Target Approach

24. Target Approach도 하나의 고정 숫자로 보지 않는다

냉동부하가 높을 때와 낮을 때 Tower Heat Rejection과 Fan 요구량이 다르므로 최적 Approach도 달라질 수 있다. Tower Cell 가동대수, Fan Speed, Water Flow와 Chiller Operating Point를 함께 분석한다.

25. 냉각수온도를 너무 낮추는 데에도 설비 제약이 있다

냉동기는 제조사별 Minimum Condenser-water Entering Temperature, Minimum Lift와 안정적인 Refrigerant/Control 조건이 존재할 수 있다. 따라서 최적화는 Chiller Manufacturer Limit와 Control Stability를 제약조건으로 둔다.

26. 단계별 Set Point Test로 실제 최적점을 찾는다

유사한 Cooling Load와 Wet-bulb 조건에서 Condenser-water Set Point를 작은 단계로 변경하고 충분히 안정화한 뒤 Chiller kW, CT Fan kW와 Pump kW를 동시에 측정한다.

그 합이 감소하는 동안은 개선 가능성이 있지만, Tower Fan 증가분이 Chiller 절감분을 넘어서는 지점부터는 더 낮은 Set Point가 유리하지 않을 수 있다.

27. Cooling Tower Cell Staging도 함께 검토한다

같은 열부하를 적은 Cell의 높은 Fan Speed로 처리할지, 여러 Cell을 낮은 Speed로 운전할지에 따라 Fan Power와 Approach가 달라진다. 따라서 Set Point와 Fan Speed뿐 아니라 Cell 가동대수도 운전변수로 포함한다.

28. 수질과 Legionella 관리 같은 비에너지 제약도 중요하다

Cooling Tower는 증발·농축이 반복되는 수계설비이므로 Water Treatment, Blowdown, Scale/Fouling, Drift와 위생관리 조건을 만족해야 한다. Energy Set Point가 수질·안전관리 기준보다 우선할 수 없다.

29. M&V는 동일한 Wet-bulb와 IT/Cooling Load 조건으로 보정한다

냉각탑 Set Point 변경 전후의 전력을 단순 비교하면 날씨와 IT Load 차이가 섞인다. 따라서 Outdoor Wet-bulb와 Cooling Load를 주요 조정변수로 두고 Chiller + Cooling Tower + 관련 Pump의 System kWh를 평가한다.

30. 18단계 Cooling Tower Optimization Process

① IT/Cooling Load → ② Outdoor WB → ③ CW Supply/Return T → ④ Approach → ⑤ CT Fan kW → ⑥ Fan Speed → ⑦ Cell Status → ⑧ Chiller kW → ⑨ Pump kW → ⑩ Current Set Point → ⑪ Equipment Limits → ⑫ Step Test → ⑬ Stabilize → ⑭ System kW → ⑮ Optimal Approach → ⑯ Reset Curve → ⑰ M&V → ⑱ 지속 Monitoring

31. 확대응용 — Wet-bulb Reset에서 Plant-level Optimization으로

단순 Reset Curve는 구현이 쉽지만 실제 최적점은 Chiller Load, Chiller 조합, Tower Cell, Water Flow와 습구온도에 따라 달라진다. 따라서 가능한 Set Point 조합별 System kW를 예측해 가장 낮은 운전점을 선택하는 방식으로 발전시킬 수 있다.

33. Evidence & Measurement Boundary

Evidence C | Field Diagnosis / Heat-rejection Alternative
확보자료에서 직접 확인되는 내용은 다중 IDC의 PUE·냉방설비 분석 이후 개선대안으로 고효율 EC Fan 교체, 외기냉방과 함께 냉각탑 설정온도 최적화의 절감효과와 투자경제성을 검토했다는 점이다.

현재 확보 Source에서는 냉각탑 설정온도 변경만으로 달성한 독립적인 최종 실측 절감률·절감금액은 확인되지 않는다. 따라서 예상 잠재량을 실제 달성성과로 표현하지 않는다.

Wet-bulb Reset, Approach Optimization, Cell Staging, 단계별 Test와 AI Plant-level Optimization은 이 개선대안을 실제 현장에 적용·고도화하기 위한 기술적 확장이다.
