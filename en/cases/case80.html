CASE80 · Data centers · Chiller staging guide

Diagnosing excess chiller operation with actual and required running counts

A data-center operating guide compares active chillers with the estimated number needed for cooling load. Count differences prompt an operating review rather than an automatic savings claim.

01 · CASE ANALYSIS

Ask whether the running count is justified

Compare cooling demand, available unit capacity, partial-load performance and the actual number operating. Low loading across many units can indicate an inefficient staging condition.

Required count is an analytical guide that must include service and reserve conditions; it is not simply load divided by nameplate capacity.

02 · CASE ANALYSIS

Read the source example correctly

The guide illustrates eight units running against seven required and a recommendation to stop one. It is an example of guidance, not proof of an achieved 8 → 7 operating change.

Do not substitute manufacturing results from CASE64 for a completed data-center CASE80 result.

03 · CASE ANALYSIS

Evaluate combinations rather than count alone

Compare unit kW/RT over the actual load range, supply/return temperatures, cooling-water conditions and associated pump/tower electricity.

Keep minimum run time, staging hysteresis, available redundancy, start limits and cooling stability in the feasible operating set.

04 · CASE ANALYSIS

Verify a supervised trial

Review the recommendation with operators, test in a suitable window and track cooling load, total plant electricity and thermal service.

The source establishes count-based diagnosis and guidance; it does not report an isolated final savings percentage or annual saving.
