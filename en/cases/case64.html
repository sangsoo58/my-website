CASE64 · Manufacturing · Chiller staging program

Distinguishing an eight-to-seven-unit staging change from the broader program result

Historical excess online capacity led to staged operation changes within a real-time utility-efficiency program. The reported 27% intensity improvement reflects combined program activities, not one stopped chiller alone.

01 · CASE ANALYSIS

Installed reserve differs from running reserve

Reliable plant capacity does not require every reserve unit to consume energy continuously. Assess online chiller count and associated pumps against actual cooling demand.

Part-load curves and auxiliary power determine efficient staging rather than a rule that fewer units are always better.

02 · CASE ANALYSIS

Source diagnosis and applied change

Historical 5°C data indicated six analytically required units versus eight running, with source load around 75%.

The actual program later changed operation from eight to seven. The analytical six-unit value is not presented as the achieved operating count.

03 · CASE ANALYSIS

Real-time program rather than an isolated switch

The project installed metering and analysis for chillers, CDA and boilers, then progressed to tests and operating guidance.

Unit efficiency, load allocation, operating conditions and poor-performing equipment were reviewed alongside staging.

04 · CASE ANALYSIS

Keep the outcome attribution correct

The program material records eight-to-seven operation and approximately 27% equipment-intensity improvement, with broader records showing 1.20 → 0.88 kW/RT.

These combined results cannot all be credited to one shutdown. Project-wide monetary totals have different dates/scopes and are not assigned as CASE64’s isolated benefit.

05 · CASE ANALYSIS

Operating constraints and verification

Review service temperature, remaining-unit limits, pump flow and reserve before staged reduction. Use hysteresis and adequate runtime conditions when translating tests to controls.

Track total plant intensity over comparable cooling demand and condenser conditions, not only the count of running units.

Source-value comparisons

Evidence & interpretation

The 27% is a program-level reported intensity result. It is not an isolated saving caused solely by changing eight units to seven, and no project-wide monetary total is reassigned here.

Source basis: Historical chiller operating analysis and utility optimization program progress/completion material.
