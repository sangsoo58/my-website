CASE84 · Manufacturing · Extrusion / Test & Adjust

Comparing three extrusion tests when production conditions change

Three anonymized tests distinguish matched-condition electricity reduction from production-normalized intensity improvement. The comparison screens repeatable operating opportunities without claiming annual savings.

01 · CASE ANALYSIS

Determine which comparisons are direct

Tests 1 and 2 had the same major production conditions: 220 minutes, 259.20 kg, 12,000 pieces and 91.67% time utilization.

Test 3 increased production and running time. Its electricity increase must be evaluated against the additional output rather than treated as worsening efficiency by itself.

02 · CASE ANALYSIS

Use the reported intensity values

Electricity was 402, 297 and 468 kWh for Tests 1, 2 and 3. Source intensities were 1.5494, 1.1443 and 1.2604 kWh/kg.

The published electricity and weight values are rounded. Retain the original analysis intensities instead of silently replacing them with ratios from rounded table values.

03 · CASE ANALYSIS

Interpret each test result

Test 2 electricity fell approximately 26.12%, while reported intensity improved 26.15%. Matching production makes this the most direct test comparison.

Test 3 production rose 43.33% and running time 40.91%, but electricity rose 16.42%. Reported intensity improved 18.65% against Test 1; it was approximately 10.15% higher than Test 2.

04 · CASE ANALYSIS

Use the comparison as a screening result

The next question is whether Test 2 intensity can be reproduced at Test 3 production. Repeat matched tests while checking product mix, good output, warm-up, downtime and metering intervals.

Three tests do not establish annual verified savings, factory-wide performance or long-term persistence. Extend the work with a valid adjusted baseline and repeated observations.
