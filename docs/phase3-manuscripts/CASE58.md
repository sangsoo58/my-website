# CASE 58 | 응용사례 — 냉각수펌프 설계유량 적용 Test를 통한 펌프 운전점 및 소비동력 최적화

## 현장 질문
냉각수펌프 실제 공급유량이 설계보다 과다하다면, 유량을 줄였을 때 Pump Power 절감이 Chiller Power 증가보다 큰가?

## 진단
프로젝트에서 **냉각수펌프 대당 공급유량 설계대비 과다**가 System Loss로 확인되었다.

Master Schedule의 절차:
**펌프 효율분석 → 설계유량 적용 Test → 결과분석 → 확대절감 검토**

## Measurement Boundary
최소한 다음을 함께 측정한다.

- Cooling Water Flow
- Pump ΔP / Head
- CWP kW
- 냉각수 입·출구온도
- 냉동부하 RT
- Chiller kW / kW/RT
- 가능하면 Cooling Tower Fan kW

유량을 줄이면 Pump Power는 감소할 수 있지만 응축조건 악화로 Chiller Power가 증가할 수 있다.

**Psystem = Pchiller + PCWP + PCT Fan**

## 예상효과
당시 진행 중 Item에서 약 **0.6억원/년**의 예상 절감효과가 제시되었다.

**Evidence Boundary:** 완료 후 독립 실측성과가 아니라 Improvement Potential이다.

## Consultant's Point
목표는 Minimum Pump kW가 아니라 **Minimum System kW**다.
