# CASE 64 | DEEP DIVE 후보 — 냉동기 가동대수 8대→7대 최적화를 통한 시스템 에너지원단위 개선

**편집상태:** PHASE 3 DRAFT / USER REVIEW REQUIRED  
**배치안:** PART 3 · Chapter 11 · 냉동기 Plant 최적화  
**Evidence:** B · Program-level Verified Result  
**Web:** /cases/case64.html

## 현장 질문
현재 부하에 비해 많은 냉동기가 저부하로 운전될 때, 필요한 신뢰성을 유지하면서 몇 대를 운전해야 Plant 전체효율이 가장 좋은가?

## 과거 진단
2007년 P6 5℃ 냉동기 분석자료에는:

- 분석상 필요 가동대수: **6대**
- 실제 가동대수: **8대**
- 당시 부하율: 약 **75%**

가 기록되어 있다.

## 실제 적용
운전최적화 프로그램을 이용한 실제 활동에서는 **8대 → 7대**로 한 단계 줄여 적용했다. 이론적 최소 6대로 즉시 줄이지 않고 생산안정성·부하변동·냉수조건·예비력을 고려해 단계적으로 접근한 사례다.

## Program Result
프로젝트 자료에는 다음이 함께 기록되어 있다.

- 설비 가동대수 최적화: **8대 → 7대**
- 설비 효율(원단위): **27% 개선**

## 해석 주의
27% 전체를 ‘냉동기 1대 정지’의 단독효과로 표현하지 않는다. 동일 프로그램에서 호기별 효율분석, 고효율설비 우선가동, 저효율설비 개선이 함께 수행되었다.

또한 프로젝트 전체 연간 절감금액은 문서 버전별 집계범위가 달라 CASE64 단독성과로 귀속하지 않는다.

## Staging Rule
필요대수는 정격 RT만으로 정하지 않고 다음을 함께 고려한다.

**현재 부하 + 호기별 효율곡선 + Pump/Tower 보조동력 + 예비력 + 최소운전시간 + 기동제약**

## Consultant's Point
목표는 최소 가동대수가 아니라 **신뢰성을 만족하면서 System kW/RT가 가장 낮은 최적 가동대수**다.
