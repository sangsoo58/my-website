## 현장 질문

일반적인 운전개선이 이미 상당 부분 수행된 고효율 제조시설에서, 다음 절감기회는 어디에서 찾을 수 있는가?

## 분석 접근

냉동기와 공기압축기의 수요·공급 Balance, 유량·온도·압력·밸브 개도율, 가동대수, 설비별 성능을 같은 운전상황에서 연결해 보았다. Big-data의 의미는 데이터량 자체보다 **여러 변수의 관계가 어긋나는 순간을 찾는 것**이었다.

주요 개선방향은 수요·공급 Balance, 유량·온도·압력·밸브 Set Point 최적화, 제어로직 개선, 가동대수 조정, 성능우위 설비 우선운전, 시스템 손실 최소화, 성능열위 설비의 유지보수였다.

## 제안단계 절감잠재량

분석대상 2개 생산거점의 연간 에너지비용은 약 **14,044,102천원**, 예상 절감금액은 **634,042천원/년**, 합산 잠재율은 약 **4.5%**였다.

세부 잠재율:
- 2공장 냉동기 A동: **9.7%**
- 2공장 냉동기 B동: **3.9%**
- 2공장 공기압축기: **3.0%**
- 3공장 냉동기: **3.0%**
- 3공장 공기압축기: **6.7%**

이 값은 확정 절감실적이 아니라 원 제안서의 사전 가능성 분석이다.

## 분석에서 운전규칙으로

고효율 현장에서는 큰 이상보다 동일 수요조건에서 반복되는 작은 Performance Gap이 중요하다. 수요가 비슷한데 전력이 다른 구간, 부하가 같은데 가동대수가 다른 구간, 밸브개도와 유량의 관계가 달라지는 구간을 찾아 제어상태를 역추적한다.

## M&V

실행 후에는 생산량, 냉동부하, 외기조건, 압축공기 수요가 달라질 수 있으므로 단순 Before/After보다 조건을 반영한 Baseline과 Actual을 비교한다.

## Consultant's Point

고효율 현장의 다음 절감기회는 평균값보다 **같은 조건에서 왜 결과가 달랐는가**라는 비교에서 발견되는 경우가 많다.
