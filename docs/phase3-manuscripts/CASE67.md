## 현장 질문
보일러 N㎥/ton이 나빠졌을 때 낮은 부하율, 과잉공기, 높은 Stack Temperature와 열교환 성능저하 가운데 어떤 원인이 영향을 주는지 데이터로 좁힐 수 있는가?

## Field Correlation
2008년 Utility 운전특성 분석에서는 보일러 효율 영향인자로 다음을 분석했다.

- 최종 배기가스 온도
- 배기가스 O₂ 농도
- 부하율
- 외기온도
- N㎥/ton

자료에는 **배기가스 온도를 낮게 운전할수록 효율이 높아지는 특성**, **배기가스 O₂ 농도를 낮게 운전할수록 효율이 높아지는 특성**이 기록되어 있다.

## 해석
O₂가 낮을수록 무조건 좋은 것이 아니다. Excess Air를 줄이면 Stack Loss를 줄일 수 있지만 너무 낮아지면 CO·미연분·Flame Stability 문제가 생길 수 있다.

따라서 현장 개선은:

**Trend → Correlation → 유사부하 비교 → Sensor 검증 → Burner/Heat-transfer 점검 → Test → N㎥/ton 재검증**

순서로 수행한다.

## Monitoring 항목
2차년도 보일러 Monitoring 계획에는 Gas Flow·Pressure·Temperature, Steam Flow·Pressure·Temperature, 배기가스 전·후단 온도, O₂ 농도와 Load Factor가 포함되어 있었다.

## Evidence Boundary
현재 확보자료에서는 O₂ 또는 배기가스온도 조정만으로 달성한 독립 최종 절감률·절감금액은 확인되지 않는다. 따라서 상관관계를 실제 검증성과로 바꾸지 않는다.

## Consultant's Point
원단위 악화는 결과이고 O₂·Stack Temperature는 **원인을 좁히는 진단변수**다. 상관관계는 결론이 아니라 Test 대상을 선정하는 근거다.
