## Chapter Lens

개별 Utility가 효율적으로 보여도 전체 제조 Utility가 최적이라고 할 수 있는가?

반도체·디스플레이 제조시설에서는 냉동기, 공조, CDA, 보일러가 서로 다른 설비처럼 운영되지만 생산환경을 유지한다는 하나의 목적을 공유한다. 따라서 단일 설비의 정격효율보다 **생산부하와 Utility 수요를 같은 시간축에서 연결하고, 가동대수·Set Point·부하분담·우선운전을 함께 조정하는 것**이 중요하다.

### CASE 42 | DEEP DIVE — Multi-site Utility 운전최적화와 실시간 효율관리

단일 생산시설 Utility 분석에서 출발해 2개 생산거점 6개 공장으로 범위를 확대하였다. CDA·냉동기·보일러의 5분 데이터를 비교하고 UPI·원단위·부하율·가동대수로 실제 운전효율을 평가했다.

CDA에서는 원단위가 **0.12897 → 0.12627 kW/N㎥**, 약 **2.09%** 개선되었다. 전체 프로젝트에서는 11개 최적화 적용항목의 **연간 16.2억원 절감 실적**과 추가 3개 항목의 **연간 3.5억원 절감 가능성**을 구분한다.

**BOOK NOTE |** 19.7억원/년은 실적과 잠재량을 합한 Portfolio 규모다. 전부를 검증성과로 표현하지 않는다.

**PRACTICE |** 총사용량보다 Utility 생산량과 연결된 KPI를 사용하고, 공장 간 성능차이를 운전가이드로 변환한다.

### CASE 43 | 응용사례 — 냉동·공조·압축공기 Utility Balance

냉동기의 평균 UPI 약 **0.84 kWh/RT**, 평균 COP **4.20**, 평균 부하율 **55%**가 관찰되었다. 실제 평균 가동대수는 약 **2.1대**, 부하기준 필요대수는 약 **1.2대**였다.

공조에서는 일부 필터차압이 약 **19~22 mmAQ**, 비교설비는 **12~13 mmAQ** 수준이었다. CDA는 월평균 UPI 약 **0.126 kWh/m³**, 시스템 손실율 평균 약 **3.1%**였지만 1분 데이터에서는 순간 최대 **31.7%**까지 관찰되었다.

분석에서 산정한 Utility 절감잠재량은 **444,832 kWh/년**, 약 **4.3%**, 약 **49.8백만원/년**이었다.

**EVIDENCE |** 이는 2018년 운전데이터 기반의 제안단계 잠재량이며 개선 후 확정 실적이 아니다.

### CASE 44 | DEEP DIVE — 4개 생산시설 Utility Benchmark

4개 생산시설의 저온·고온 냉동기와 CDA를 동일 KPI로 비교했다.

저온냉동기 UPI는 약 **0.54 / 0.52 / 0.40 / 0.46**, 냉수펌프 포함 시 **0.65 / 0.66 / 0.50 / 0.56**이었다.

고온냉동기는 단품 약 **0.37 / 0.33 / 0.37 / 0.39**, 냉수펌프 포함 약 **0.50 / 0.44 / 0.46 / 0.48**이었다.

CDA UPI는 약 **0.124 / 0.114 / 0.127 / 0.110**이었다.

**CASE LESSON |** Benchmark의 목적은 가장 낮은 숫자를 복사하는 것이 아니다. Best Performance가 만들어진 부하율·가동대수·By-pass·압력·제어조건을 찾아 다른 시설에서 재현 가능한 운전원리로 바꾸는 것이다.

### CASE 45 | 응용사례 — 고효율 공장의 잔여 절감기회

이미 일반적인 최적화가 진행된 생산시설에서는 큰 낭비보다 작은 수요·공급 불균형과 설정값 차이를 찾았다.

2개 생산거점의 분석대상 연간 에너지비용은 약 **14,044,102천원**, 예상 절감금액은 **634,042천원/년**, 합산 잠재율은 약 **4.5%**였다.

세부 잠재율은 2공장 냉동기 A동 9.7%, B동 3.9%, 공기압축기 3.0%, 3공장 냉동기 3.0%, 공기압축기 6.7%였다.

**EVIDENCE |** 제안서의 사전 가능성 분석이며 실제 M&V 완료성과가 아니다.

## Chapter Synthesis

CASE42~45를 함께 보면 Multi-Utility 최적화는 다음 흐름으로 정리할 수 있다.

**Data Quality → KPI Normalization → Multi-site Benchmark → Demand/Supply Balance → Selection/Staging/Set Point → Operating Rule → M&V**

### Chapter Review

- 총사용량보다 생산·Utility 산출량을 반영한 KPI를 사용한다.
- 같은 KPI라도 Measurement Boundary가 다르면 직접 비교하지 않는다.
- 평균값과 1분·5분 Trend를 함께 본다.
- Best Performance의 숫자가 아니라 운전조건을 이전한다.
- 적용성과와 잠재량을 분리한다.
- 분석결과는 Dashboard가 아니라 현장 운전 Rule로 연결한다.
