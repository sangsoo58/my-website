# CASE 53 | 응용사례 — 냉동기 냉수 출구온도 Set Point 상향을 통한 냉동효율 개선 및 전력절감

## 현장 질문
생산공정과 공조·제습조건을 만족하면서 냉수 출구 Set Point를 어디까지 높일 수 있고, 어느 지점에서 Chiller Plant 전체 효율이 가장 좋아지는가?

## 데이터
냉동기 가동상태, RT, 냉수 입·출구온도, 냉수유량, 냉각수 입·출구온도와 유량, 냉동기 kW, 냉수·냉각수펌프 전력을 함께 본다.

## KPI
**kW/RT = 냉동기 소비전력 ÷ 실제 냉동부하**

Set Point 변경 후 kW만 줄었다고 효율개선으로 판단하지 않는다. 부하가 달라질 수 있으므로 RT로 정규화한다.

## Test & Adjust
현재 Set Point에서 Baseline을 확보하고, 생산·공조 담당자와 허용범위를 정한 뒤 작은 단계로 상향한다. 각 단계에서 냉수 ΔT, Flow, RT, kW/RT와 공정·온습도·제습상태를 확인한다.

## System Boundary
최종 판단은 Chiller Only보다 다음 범위를 권장한다.

**Chiller kW + CHW Pump + CW Pump + Cooling Tower Fan → System kW/RT**

## Consultant's Point
가장 높은 냉수온도가 최적점은 아니다. 생산·온습도·제습·안정운전을 만족하는 범위에서 **Plant 전체 전력이 최소가 되는 지점**을 찾아야 한다.

## Evidence Boundary
운전조건 최적화 Field Test 사례. 일반적인 ‘1℃당 절감률’을 현장실적으로 대체하지 않고 해당 시스템에서 단계적으로 직접 검증한다.
