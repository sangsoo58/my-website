# CASE 59 | 응용사례 — CDA 공기압축기 저효율 호기 진단 및 성능저하 원인분석을 통한 효율개선

**편집상태:** PHASE 3 DRAFT / USER REVIEW REQUIRED  
**배치안:** PART 4 · Chapter 14 · 공기압축기 시스템 운전최적화  
**Evidence:** C · Diagnosis / Improvement Activity  
**Web:** /cases/case59.html

## 현장 질문
동일 수요조건에서 특정 Compressor의 Specific Energy가 지속적으로 높다면, 운전조건 차이와 실제 성능저하를 어떻게 분리할 것인가?

## 진단 접근
호기별 kW와 CDA 생산유량을 연결하여 Specific Energy를 비교하고, Flow·Pressure·Load 조건이 유사한 구간에서 성능편차를 본다.

가능한 원인:
- 기계적 성능저하
- Cooling / Filter / Dryer 영향
- 압력조건
- Sensor 오차
- Idling / Part-load 운전

## Baseline 확장
충분한 데이터가 있으면 Flow·Pressure·Load로 정상 Specific Energy를 예측하고 **실측 − 예측 Residual**을 사용해 성능 Drift를 탐지할 수 있다.

## Evidence Boundary
실제 프로젝트에서 저효율 호기 점검 및 저하 원인·개선 활동이 추진되었고, 1년 CDA 분석에서 Idling·압력편차·과다가동·제조원단위 문제도 확인되었다.

다만 이 활동만의 독립 최종 절감 kW·절감률·연간금액은 귀속하지 않는다.

## Consultant's Point
호기 Ranking은 설비 폐기의 근거가 아니라 **어디를 먼저 점검하고 정비할지 정하는 진단 우선순위**다.
