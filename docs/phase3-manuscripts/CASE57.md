# CASE 57 | 응용사례 — 5℃·13℃ 냉수계통 부하분담 최적화

**편집상태:** PHASE 3 DRAFT / USER REVIEW REQUIRED  
**배치안:** PART 3 · Chapter 11 · 냉동기 Plant 최적화  
**Evidence:** C · Test Plan / Optimization  
**Web:** /cases/case57.html

## 현장 질문
서로 다른 온도등급의 냉수계통 사이에서 부하를 어떻게 나누어야 불필요한 저온냉수 사용과 냉동기 가동대수를 줄일 수 있는가?

## 최적화 계획
실제 프로젝트에는 다음 활동이 명시되어 있다.

- 5℃/13℃ 부하분담 최적화
- OAC 13℃ 밸브 **15~50% Close**
- 13℃ 냉동기 가동대수 감소 확인
- 외기 노점온도 **22℃ 이하** 조건 검토
- 13℃ 냉동기 **1대 정지 Test**
- 운전관리 기준 수립

## 판단기준
저온 냉수의 과다사용을 줄인다고 해서 공정·제습·공조 조건을 훼손해서는 안 된다. 계통 간 Load Transfer 후에는 Chiller + Pump 전력과 온습도·생산조건을 함께 확인한다.

## Evidence Boundary
본 CASE는 **실행계획과 최적화 Test 설계**가 확인되는 사례다. 과거 진단의 평균 부하율·부하분담률·ΔT·Bypass 분석은 Test 설계의 배경자료이며, 이 활동만의 독립 최종 절감금액은 귀속하지 않는다.

## Consultant's Point
냉수계통 최적화는 ‘어느 온도계통이 더 효율적인가’보다 **어떤 부하를 어느 온도등급으로 공급해야 전체 Plant 전력이 최소가 되는가**를 묻는 문제다.
