# CASE 60 | DEEP DIVE 후보 — 냉동유 첨가제 적용 전·후 kW/RT 비교를 통한 냉동기 효율개선 효과 검증

**편집상태:** PHASE 3 DRAFT / USER REVIEW REQUIRED  
**배치안:** PART 3 · Chapter 11 · 냉동기 Plant 최적화  
**Evidence:** A · Field Test / Null Result  
**Web:** /cases/case60.html

## 현장 질문
냉동유 첨가제가 Oil Fouling을 완화해 냉동기 효율을 실제로 개선하는가?

## 가설
냉동유가 냉매계통에 유입되어 열교환기 내벽에 부착되고, 열전달을 방해할 수 있다는 가설에서 출발했다.

## Test 설계
적용 전부터 다음 데이터를 확보한다.

- Chiller kW
- 실제 냉동부하 RT
- 냉수 Set Point
- 냉각수 입·출구온도
- 부하율
- 동시 정비·세관·Set Point 변경 여부
- 계측 신뢰성

비교 KPI는 kW/RT이며, 적용 전·후 운전조건을 최대한 맞춘다.

## 결과
실제 프로젝트에서 구매·분석계획·투입·효율분석·확대평가까지 진행했으나 **최종 결과는 ‘효과 없음’**으로 정리되었다.

따라서 CASE60에는 절감 kW·절감률·연간 절감금액을 부여하지 않는다.

## Consultant's Point
좋은 에너지절감 사례는 모든 Test가 성공한 사례가 아니다. **가설을 현장에서 검증하고 효과가 없으면 확대적용을 중단하는 것**도 중요한 의사결정이다.

## Evidence Boundary
Oil Fouling 개선원리는 당시 프로젝트의 가설이며, 현장 Test가 그 가설의 유효성을 입증한 것으로 표현하지 않는다.
