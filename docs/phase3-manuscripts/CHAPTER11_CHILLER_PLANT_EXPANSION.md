## CHAPTER 11
# 냉동기 Plant 최적화

**COP가 높은 냉동기를 먼저 운전하는 것만으로 Plant 전체가 최적화될까?**

냉동기 Plant는 냉동기뿐 아니라 냉수펌프·냉각수펌프·냉각탑이 함께 운전되는 시스템이다. 따라서 개별 냉동기 COP가 높더라도 냉수·냉각수 유량이 과다하거나 보조동력이 크고, 가동대수가 실제 부하보다 많으면 Plant 전체 효율은 낮아질 수 있다.

**CHAPTER LENS |** 냉방부하와 생산·온습도·신뢰성 제약을 만족하면서 냉동기·펌프·냉각탑의 **Plant kW/RT**를 최소화하는 운전조합은 무엇인가?

기존 CASE09·10이 호기별 COP, 월별 우선가동, Plant 가동대수와 보조동력의 통합최적화를 다뤘다면, 확장 CASE53~64와 CASE78은 Set Point, 실제 호기 교체운전, 유량, Load Dispatch, Staging, Data Quality까지 더 구체적인 운전행동으로 내려간다.

---

## CASE 53 | 응용사례 — 냉수 출구온도 Set Point 상향 Test

냉수온도는 낮을수록 항상 좋은 것이 아니다. 실제 공정·공조·제습이 요구하는 온도보다 낮은 냉수를 지속 공급하면 냉동기의 Lift가 커져 불필요한 전력이 발생할 수 있다.

분석에서는 냉동기 kW뿐 아니라 냉수유량과 공급·환수 ΔT로 실제 RT를 계산하고, 다음 KPI를 사용한다.

**Chiller kW/RT = Chiller kW ÷ Actual Cooling Load(RT)**

Set Point를 단계적으로 조정한 뒤 생산품질·온습도·제습조건이 유지되는지 확인하고, 냉동기 단품이 아니라 냉수펌프·냉각수펌프·냉각탑을 포함한 Plant 전력까지 확인한다.

**OPERATING RULE |** 가장 높은 냉수온도가 아니라, 필수 서비스조건을 만족하면서 **System kW/RT가 최소가 되는 냉수 Set Point**를 찾는다.

## CASE 55 | 응용사례 — 실제 냉수 사용량에 맞는 펌프 용량 재정렬

2,000 USRT급 5℃ 냉수계통의 대표 설계 펌프는 약 **150 kW, 605 m³/h, Head 60 m**였으나 실제 운전에서는 유량과 소비전력이 설계값과 다르게 나타났다.

후속 개선 Item에서는 **“5℃ 냉수펌프 사용량에 맞는 사양 교체”**가 검토되었고, 약 **0.7억원/년**의 개선효과가 제시되었다.

**EVIDENCE C |** 위 금액은 개선 잠재량이며 완료 후 독립 검증성과가 아니다.

펌프는 kW만 비교하지 않고 실제 Flow(Q)·Head(H)·Power를 Pump Curve와 System Curve에 연결한다. 교체 외에도 VFD, Impeller Trim, 병렬펌프 대수조정, Differential Pressure Reset을 같은 Q-H 조건에서 비교한다.

## CASE 56 | DEEP DIVE — 냉동기 교체운전으로 호기별 kW/RT를 직접 비교

동일·유사 용량의 냉동기라도 실제 운전효율은 다를 수 있다. 따라서 Nameplate가 아니라 실제 운전호기를 바꾸어 Field Test를 수행했다.

- **#10 → #9:** kW/RT 약 **6.6% 감소**
- **#4 → #3:** kW/RT 약 **15% 감소**
- 후자의 5℃ 구간에서는 전력 약 **150 kW 감소**

첫 번째 Test에서는 kW/RT가 좋아졌지만 부하 증가로 총 kW는 오히려 증가했다. 이 결과는 냉동기 효율평가에서 단순 소비전력보다 **부하로 정규화한 kW/RT**가 필요한 이유를 보여준다.

**CASE LESSON |** 효율 우선순위는 설비번호가 아니라 실제 부하조건에서 측정된 Part-load Performance로 결정한다.

## CASE 57 | 응용사례 — 5℃·13℃ 냉수계통 부하분담 최적화

실제 프로젝트에서는 5℃와 13℃ 냉수계통의 부하분담을 조정하고, OAC 13℃ 밸브를 단계적으로 조정해 13℃ 냉동기 가동대수를 줄일 수 있는지 검토했다.

계획에는:
- OAC 13℃ 밸브 **15~50% Close**
- 외기 노점온도 **22℃ 이하** 조건
- 13℃ 냉동기 **1대 정지 Test**
- 운전관리 기준 수립

이 포함되어 있다.

**EVIDENCE C |** Test Plan / Optimization 단계이며 독립적인 최종 절감금액은 부여하지 않는다.

---

## CASE 58 | 응용사례 — 냉각수펌프 설계유량 적용 Test

현장진단에서는 **냉각수펌프 대당 공급유량이 설계대비 과다**한 항목이 System Loss로 확인되었다.

추진 절차는:

**펌프 효율분석 → 설계유량 적용 Test → 결과분석 → 확대절감 검토**

이며, 당시 개선 잠재량은 약 **0.6억원/년**으로 제시되었다.

냉각수유량을 줄이면 Pump kW는 감소할 수 있지만 Chiller 응축조건이 악화될 수 있으므로 다음 System Boundary를 사용한다.

**Psystem = Pchiller + PCWP + PCT Fan**

**EVIDENCE C |** 약 0.6억원/년은 진행 중 Item의 예상효과다.

## CASE 60 | DEEP DIVE — 냉동유 첨가제 Test와 Null Result

냉동유 Fouling이 열교환을 방해할 수 있다는 가설을 세우고 냉동유 첨가제를 실제 적용한 뒤 kW/RT를 비교했다.

그러나 완료보고의 최종 판단은 **“효과 없음”**이었다.

이 사례는 에너지절감 프로젝트에서 중요한 원칙을 보여준다.

**TEST → DATA → ADOPT / REJECT**

효과가 확인되지 않았기 때문에 절감률·절감금액을 새로 부여하지 않고 확대적용 근거가 부족한 것으로 정리한다.

**CASE LESSON |** 성공한 Test만 남기는 것이 아니라, 효과가 없었던 검증결과도 의사결정 Evidence다.

## CASE 62 | DEEP DIVE — 냉각수 입구온도 단계별 Test

냉각수 입구온도 20~22.5℃ 구간에서 kW/RT를 실측했다.

| 냉각수 입구온도 | kW/RT |
|---|---:|
| 20.5℃ | 0.567 |
| 21.0℃ | 0.577 |
| 21.5℃ | 0.577 |
| 22.0℃ | 0.597 |
| 22.5℃ | 0.629 |

해당 Test에서는 20.5℃에서 가장 낮은 kW/RT가 관찰되었다. 그러나 이를 연중 고정 Set Point로 사용하지 않고, 완료자료는 동절기·춘추절기와 하절기의 외기 습구조건을 구분해 운전기준을 설정했다.

완료자료의 해당 개선항목 Cost Reduction은 약 **0.6억원/년**이었다.

**IMPLEMENTATION |** 목표는 가장 낮은 냉각수온도가 아니라 Chiller와 Cooling Tower를 합한 **Minimum System kW**다.

## CASE 63 | DEEP DIVE — 고효율 냉동기의 Load Dispatch

13℃ 냉동구간에서 호기별 kW/RT와 부하율을 비교한 결과, 원단위가 가장 좋은 냉동기가 약 **60% 부하**로 운전되고, 상대적으로 불리한 다른 호기는 약 **95~105%** 부하로 운전되고 있었다.

냉수펌프 토출밸브를 조정해 부하를 재분배한 후:

**System kW/RT 0.594 → 0.556**

로 개선되었다. 개선폭은 **0.038 kW/RT**, 5,200 RT 조건에서 약 **197.6 kW**, 완료보고서의 연간 효과는 약 **1.02억원/년**이었다.

**EVIDENCE A | Verified Saving**

**CASE LESSON |** CASE56이 “어느 냉동기를 켤 것인가”를 다룬다면, CASE63은 “가동 중인 냉동기에 부하를 어떻게 배분할 것인가”를 다룬다.

## CASE 64 | DEEP DIVE — 냉동기 가동대수 8대→7대 Staging

과거 분석자료에서는 냉동기 **필요 6대 / 실제 8대**, 평균 부하율 약 **75%**가 관찰되었다.

실제 최적화 활동에서는 한 번에 6대로 줄이지 않고 **8대 → 7대**로 단계적으로 적용했다. 프로젝트 자료에는 프로그램 활용결과로 **설비 효율(원단위) 27% 개선**이 기록되어 있다.

**EVIDENCE B | Program-level Verified Result**

27% 전체를 “냉동기 한 대 정지”의 단독효과로 귀속하지 않는다. 같은 프로그램에서 호기별 실시간 효율분석, 고효율 우선가동, 저효율설비 개선이 함께 수행되었다.

## CASE 78 | 응용사례 — 반도체·디스플레이 제조시설 냉각수펌프 Benchmark

5℃ 계통 #01~#14, 13℃ 계통 #15~#23의 냉각수펌프에 대해 개별 전력·가동상태·유량·m³/kWh·부하율과 시스템의 실제·필요 가동대수를 관리했다.

핵심 KPI는:

**Running Units − Required Units**

와 동종 펌프의 **m³/kWh** 비교다.

성능열위와 과다운전은 다른 문제로 구분한다. 전자는 정비·우선운전, 후자는 가동대수·운전조합 최적화로 연결한다.

**EVIDENCE B/C |** 독립 최종 절감성과는 현재 확정하지 않는다.

## CHAPTER 11 SYNTHESIS

확장된 냉동기 Plant 최적화는 다음 네 의사결정으로 정리된다.

1. **Selection** — 어느 냉동기가 실제로 효율적인가?
2. **Staging** — 현재 부하에서 몇 대가 필요한가?
3. **Dispatch** — 가동 중인 냉동기에 부하를 어떻게 배분할 것인가?
4. **Set Point / Flow** — 냉수·냉각수·펌프 조건을 어디에 둘 것인가?

이 네 가지는 독립적인 문제가 아니다.

**Plant Load → Unit Performance → Available Combination → Flow/Temperature → Auxiliary Power → Plant kW/RT**

의 하나의 최적화 문제로 다뤄야 한다.

## CHAPTER 11 REVIEW

- 개별 COP와 Plant kW/RT를 구분한다.
- kW보다 RT로 정규화한 효율을 함께 본다.
- 가동대수와 Load Dispatch를 동시에 판단한다.
- Pump/Tower 보조동력을 포함한다.
- 생산·제습·신뢰성은 최적화보다 우선하는 제약조건이다.
- Test 결과, 잠재량, 프로그램 수준 성과를 각각의 Evidence로 구분한다.
