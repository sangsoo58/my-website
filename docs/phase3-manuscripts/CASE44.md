# CASE 44 | DEEP DIVE 후보 — 4개 생산시설 Utility 성능 Benchmark를 통한 UPI·가동대수 최적화

**편집상태:** PHASE 3 DRAFT / USER REVIEW REQUIRED  
**배치안:** PART 3 · Chapter 12 · 반도체 Multi-Utility 통합 최적화  
**Evidence:** B/C — Benchmark 사실과 절감잠재량 분리  
**Web:** /cases/case44.html

## 현장 질문

한 사업장 내부의 추세만 보지 않고 유사한 4개 생산시설을 동일 KPI로 비교하면, 실제로 재현 가능한 Best Performance와 개선목표를 찾을 수 있는가?

## 비교 전제

사업장 간 Benchmark는 계산식과 Measurement Boundary가 같아야 한다. 냉동기 단품 UPI인지, 냉수펌프까지 포함한 시스템 UPI인지가 다르면 숫자를 그대로 비교할 수 없다. CDA도 전력과 유량의 계측위치·단위·기간을 맞춰야 한다.

## 저온냉동기 Benchmark

4개 시설의 저온냉동기 연간 UPI는 약 **0.54 / 0.52 / 0.40 / 0.46**이었다. 냉수펌프까지 포함하면 약 **0.65 / 0.66 / 0.50 / 0.56**이었고, 연간 시스템 부하율은 약 **71.93 / 69.84 / 79.54 / 78.55%**였다.

가장 낮은 UPI를 그대로 목표값으로 복사하지 않는다. 냉수온도, 부하, 설비형식, 계절별 운전조건을 확인한 뒤 성능차이가 장비 자체인지 펌프운전·가동대수·부하분담 때문인지 추적한다.

## 고온냉동기 Benchmark

고온냉동기 단품 UPI는 약 **0.37 / 0.33 / 0.37 / 0.39**, 냉수펌프 포함 시 **0.50 / 0.44 / 0.46 / 0.48**이었다. 연간 시스템 부하율은 약 **94.74 / 91.21 / 93.80 / 88.06%**였다.

단품효율과 시스템효율을 분리해 보는 것이 핵심이다.

## By-pass와 CDA Benchmark

고온냉동기 냉수 Header By-pass 연평균 개도율은 약 **43 / 20 / 31 / 33%**로 차이가 있었다. 높은 개도율만으로 낭비를 단정하지 않고 최소유량·차압·말단밸브 상태를 확인한다.

CDA 연간 UPI는 약 **0.124 / 0.114 / 0.127 / 0.110**, 유량기준 시스템 부하율은 약 **90 / 90 / 80 / 89%**였다.

## 운전가이드로 전환

**Best Performance → 원인 후보 → 현장조건 확인 → 재현 가능한 운전규칙**

Benchmark의 목적은 순위를 만드는 것이 아니라 가장 좋은 성능이 만들어진 가동대수, 부하율, By-pass, 압력과 제어조건을 찾아 다른 시설에 적용 가능한 원리를 만드는 것이다.

## Evidence Boundary

현재 원고는 원자료에서 확인된 UPI·부하율·By-pass 값을 사용한다. 시설 A~D는 비식별 표현이며, 시설 간 Performance Gap 자체를 실제 절감성과로 변환하지 않는다.
