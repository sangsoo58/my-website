## Editorial 판단

Option A는 공기압축기 → 보일러 → 통합 Utility → 철강/비철/펌프/발전소로 이어져 학습 흐름이 자연스럽다. 다만 현재 Chapter 15~28 번호가 모두 변경된다.

Expanded Edition은 페이지 번호가 전면 재조정되므로 Chapter 번호 변경 자체는 기술적으로 문제되지 않는다. CASE ID는 Chapter 번호와 무관하게 C01~C82로 고정한다.

**이 문서는 제안안이며 사용자 승인 전 최종 목차로 확정하지 않는다.**
