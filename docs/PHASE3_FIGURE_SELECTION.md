# PHASE 3 — Figure Selection for Expanded Edition

Status: **BOOK PRINT CANDIDATE / USER CONFIRMATION PENDING**

## Selection principle

Production Web에 존재하는 승인 PNG 11개를 그대로 모두 책에 넣지 않는다.

선정기준:
- 분석질문을 한눈에 설명하는가
- 기존 41 CASE의 Figure/Table과 중복되지 않는가
- 수치·Evidence가 Source에서 잠겨 있는가
- 152×225 mm 내지에서 읽을 수 있는가
- 비식별·사용권 검토가 가능한가

## 권장 인쇄 Figure 수

11개 중:
- **KEEP / KEEP HIGH: 7개**
- **OPTIONAL: 1개**
- **TABLE/CALLOUT PREFERRED: 3개**

따라서 1차 Expanded Edition에서는 **7개 중심 + 필요 시 CASE44-F02 추가**가 적절하다.

## Print QA

승인 PNG:
- 1510×936 또는 1511×852 px
- 300 dpi 기준 최대 폭 약 127.8~127.9 mm

152×225 mm 판형의 본문 실사용 폭이 128 mm 이하이면 원칙적으로 300 dpi 수준이다.

단:
- 캡션·축·범례의 실제 글자크기 확인
- CMYK/Gray 변환 시 가독성 확인
- Source/비식별/Book permission 확인
이 완료되어야 최종 사용한다.
