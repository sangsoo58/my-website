## GitHub Desktop 적용
1. GitHub Desktop → `my-website` → **Show in Explorer**
2. 이 ZIP의 `cases/case84.html`을 저장소의 `cases/case84.html`에 덮어쓰기
3. GitHub Desktop Changes 확인
4. Summary:
   `Improve CASE84 SEO metadata and internal links`
5. **Commit to main**
6. **Push origin**
7. 배포 후 브라우저에서 CASE84 페이지 확인
8. Search Console에서 `case84.html` 실제 URL 테스트 후 필요 시 색인 생성 요청
