HOW TO USE THIS BOOK 사례와 Toolkit 을 활용하는 방법 CASE

는결과보다분석과정을읽는다 이 책의 40 개 CASE 는 산업과 설비는 서로 다르지만 공통적인 분석구조를 갖는다. 현장조건 확인 → 데이터 정합성 검토 → KPI 산정 → Baseline 구축 → M&V 계획 설정 → 비효율 구간 탐색 → 개선 시나리오 → 실행조건 검토 → 실행 → 성과검증(M&V)의 연결을 확인한다. 자신의 현장과 완전히 동일 한 사례를 찾기보다 유사한 데이터 구조와 의사결정 방법을 가진 사례를 찾는 것이 효과적이다. Deep Dive

는분석과정을더깊게보는사례다 Deep Dive 표시는 실제 컨설팅 과정에서 사용된 데이터·그래프·계통도·운전 관리 화면을 바탕으로 분석절차를 보다 상세하게 설명한 대표 사례다. 결과값 보다 원시데이터 → 전처리 → KPI → Baseline → 진단 → 개선변수 → 예 상효과 → 적용 → Adjusted Baseline·Actual 비교 → 검증성과의 연결을 확인한다. 실제 적용이 이루어지지 않은 사례는 예상효과 단계에서 종료될 수 있다.

예상효과와검증성과는구분해서읽는다 절감잠재량·예상효과·목표치는 개선안을 실행하기 전에 분석 또는 시뮬레이 션으로 산정한 값이다. 반면 검증성과는 개선조치 후 평가기간의 생산·외기· 운영조건 등을 반영한 Adjusted Baseline 과 Actual 을 비교하여 산정한 실 제 성과다. 설계단계 Energy Modeling 의 개선율은 준공 후 실제 절감실적 과 구분한다.
