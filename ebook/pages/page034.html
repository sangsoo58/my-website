데이터로 찾는 산업·건물 에너지절감 실무 — 34쪽

5.2 제약조건 운전최적화에서는 에너지 절감보다 먼저 반드시 지켜야 하는 조건을 정의한 다. 품질, 안전, 생산량, 말단압력, 실내온도, 공정온도, 설비 최소부하 등이 대표적인 제약조건이다. 이를 무시한 수치상 최적점은 현장에 적용할 수 없 다. 예를 들어 압축공기의 공급압력을 낮추면 전력은 줄 수 있지만 말단압력이 기 준 이하로 떨어진다면 최적운전이 아니다. 핵심 질문은 “필요조건을 모두 만 족하면서 에너지사용량을 어디까지 줄일 수 있는가?”이다. 5.3 우선가동 동일 기능의 병렬 설비는 같은 부하에서 효율이 좋은 설비를 우선가동하되 최 소부하, 기동횟수, 정비상태, 운전시간 균등화와 안정성도 함께 고려한다. 따 라서 우선가동은 단순한 설비 순위가 아니라 부하구간별로 어떤 설비를 몇 대, 어떤 순서로 운전할 것인가를 정하는 운전규칙으로 설계한다. 5.4 Set Point 압력과 온도는 높은 값이 안전하다는 관행 때문에 필요 이상으로 설정되기 쉽 다. 말단의 실제 요구조건과 시스템 손실을 계측한 뒤, 필요한 조건을 만족하 는 범위에서 Set Point 를 단계적으로 조정한다. 목적은 가능한 한 낮은 값을 찾는 것이 아니라 생산·품질·안전 조건을 안정적으로 만족하는 최소 운전범 위를 찾는 것이다.
