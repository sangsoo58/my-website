데이터로 찾는 산업·건물 에너지절감 실무 — 5쪽

HOW TO READ 이 책을 읽는 방법

데이터에서절감성과까지,

이책은하나의흐름으로연결되어있 다 이 책은 산업·건물 현장의 에너지절감을 단순한 설비교체 사례의 모음으로 설 명하지 않는다. 현장에서 무엇을 측정하고, 어떻게 정상상태를 정의하며, 어 떤 운전변수를 바꿀 수 있고, 실제 절감성과를 어떻게 검증할 것인가라는 일 련의 과정으로 접근한다. Measure → Understand → Model → Optimize → Verify Measure 에서는 계측경계와 분석단위를 정하고 필요한 생산·운전·에너지 데이터를 정의·확보한다. Understand 에서는 생산량·가동시간·부하·외기· 압력·온도와 같은 영향인자를 분석하여 정상운전과 비정상운전을 구분한다. Model 에서는 KPI 로 에너지성능을 비교하고, 주요 영향인자를 반영한 Baseline 으로 정상 에너지사용량을 설명·예측한다. M&V 의 계측경계, Baseline 기간, 영향인자와 평가방법은 Measure 와 Model 단계에서 미리 계획한다. Optimize 에서는 생산·품질·안전·서비스 조건을 유지하면서 실제로 변경 가 능한 Set Point·가동대수·운전순서와 운전조건을 찾는다. Verify 에서는 평 가기간의 생산·외기·운영조건을 반영한 조정 기준사용량(Adjusted Baseline)과 Actual 을 비교하여 실제 절감성과를 검증하고, 절감잠재량·예 상효과·목표치와 검증성과를 구분한다.
