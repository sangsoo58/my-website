5.5

시나리오평가 현재운전과 개선운전은 가능한 한 동일하거나 유사한 부하조건에서 비교한 다. 조건이 다르면 Baseline 모델로 생산량, 외기온도, 운전시간 등의 차이를 보정한다. Scenario A: 고효율 설비 우선가동 Scenario B: 저부하 시간대 가동대수 축소 Scenario C: 말단조건을 만족하면서 Set Point 하향 Scenario D: 우선가동 + 가동대수 + Set Point 통합 적용 각 시나리오는 에너지사용량뿐 아니라 생산량, 품질, 안전, KPI 와 운전안정 성을 함께 평가한다. 절감률이 가장 큰 안보다 절감효과가 충분하면서 현장에 서 지속적으로 실행할 수 있는 안을 최적안으로 선정한다. 절감량 = Adjusted Baseline − Actual 5.6

적용과재조정 선정한 시나리오는 현장에서 시험운전한 뒤 변경조건, 적용시간, 생산량·부 하, 에너지사용량과 KPI 를 기록한다. 운영자 의견, 품질·민원, 설비 이상 여 부와 절감량을 확인하고 문제가 없으면 적용범위를 확대한다. 예상효과가 나타나지 않거나 생산조건에 영향을 주면 Set Point, 가동대수 또는 운전범위를 재조정한다. “측정 → 시나리오 설정 → 시험운전 → 성과검 증(M&V) → 재조정”을 반복하는 것이 지속적 최적화의 핵심이다.
