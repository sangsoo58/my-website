에서활용법을익히고, APPENDIX Toolkit

을현장에서사용 한다 현장방문 전에는 에너지진단 현장조사 Checklist 와 MES·EMS 데이터 요청 서를, 데이터 분석단계에서는 BEMS 데이터 정합성·Baseline 모델 평가 Checklist 와 KPI 공식을 활용한다. 필요한 Toolkit 은 PART 7 의 활용 가 이드를 따라 APPENDIX A~O 에서 선택해 사용한다. 성과검증에는 M&V 결과표 Template 을 적용하고, Python 분석 구현 순서는 원시데이터에서 Baseline 예측과 절감량 집계까지의 분석과정을 재현할 때 활용한다.
